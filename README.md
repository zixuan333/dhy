# 辟雍学府 2.0 Web V0.1

这是一个无需服务器即可运行的免费静态网站原型。

## 已完成
- 首页
- 我的密探库：新增/删除、等级、星级、命盘、攻击、生命
- 招募记录：卡池、抽数、绝密数、角色；自动统计总抽数/总绝密/平均出绝密
- 操作记录仪：自定义阵容、增加回合、普攻/技能/防御/特殊、复制上一回合、复制文本
- 浏览器 LocalStorage 本地保存
- JSON 数据导出
- PWA 基础支持（可添加到手机主屏幕）

## 本地打开
直接双击 index.html 即可查看基础页面。
如果希望 PWA/Service Worker 正常工作，建议用本地服务器：

```bash
python3 -m http.server 8080
```

然后打开 http://localhost:8080

## 免费上线方法（推荐 Vercel）
1. 注册 GitHub
2. 新建一个仓库，把本文件夹里的文件上传
3. 登录 Vercel
4. 选择 Import Project / 导入项目
5. 选择刚才的 GitHub 仓库
6. Framework Preset 选择 Other
7. 点击 Deploy

几分钟后会获得一个免费的 `*.vercel.app` 网站地址。
