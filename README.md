# 广陵秘学 Web V0.2

这是根据当前已经确认的产品逻辑制作的静态网站原型。

## 已实现

- 暖米黄 / 杏色视觉方向
- 首页 3 × 2 核心入口
- 多游戏账号切换
- 我的密探：等级、星级、修为、攻击、生命、命盘、星石
- 攻略库：搜索、攻略卡片、适配度、复现人数、报错 / 待复核机制
- 攻略详情：阵容配置、回合操作、作者备注、与当前账号对比
- 发布攻略：自动导入当前账号密探数据，可修改本篇配置，可选择同步回我的密探
- 动作符号：A / ↑ / ↓，支持 1A / 2↑ 这种行动顺序
- 草稿 / 发布入口
- 限时攻略提示与结束日期字段
- 星石记录：纯文字，无图片
- 招募记录：第一层仅显示卡池；点进后查看第几金、间隔抽数、UP / 歪 / 保底 / 双金
- 数据导出 JSON
- 密探图鉴暂留空

## 当前限制

- 数据目前保存在浏览器 localStorage，并非云端。
- 角色头像目前使用文字占位圆角头像，正式密探图片尚未接入。
- “适配度”目前展示原型逻辑，后续需要根据真实密探、命盘、星石条件做计算规则。
- 限时攻略 30 天归档后自动删除尚未连接后台定时任务。
- 玩家公共攻略库现在仍是本地原型；要让不同玩家共同上传和查看，需要下一阶段接 Supabase 云数据库与登录。

## 更新 Vercel 网站

如果你当前 Vercel 项目已经连接 GitHub：

1. 解压本压缩包。
2. 打开 GitHub 上你现在用于 Vercel 的仓库（例如 `biyong-web`）。
3. 删除或替换旧的 `index.html`，并上传本版本的：
   - `index.html`
   - `styles.css`
   - `app.js`
4. 提交 Commit changes。
5. Vercel 会自动重新部署，一般几十秒到几分钟后原网址就会更新。

不需要重新创建 Vercel 项目，也不需要重新绑定域名。
